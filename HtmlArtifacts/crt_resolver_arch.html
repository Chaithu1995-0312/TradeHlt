Resolver Role

CRTStateResolver is the market-reality / shadow resolver for the M15 CRT state vocabulary. It reads market_crt_states.yaml, classifies each bar's feature values into declared feature states, evaluates state predicates in YAML order, applies lifecycle resets and transition validity, then returns one CRT state name.

Surface What it owns What it does not own
Resolver Shadow/declarative M15 state classification, overlays, parity work, diagnostics, and research state tracks. Live execution authority. The CRT engine remains the execution authority for trading.
YAML State order, feature-state predicates, transition list, threshold names/values, and lifecycle knobs. Parent C1/C2/C3 runtime production. Parent-timeframe C1/C2/C3 is driven by ParentCRTTrack.
Code Feature supply checks, HTF/gap reset handling, funnel gates, sticky dwell, transition validity, engine-event injection. A replacement for CRTEngine.process_candle().

Evaluation Order

The resolver evaluates YAML states in this first-match order. RANGE is the ground state and final fallthrough.

EXECUTION RETEST EXPANSION DISPLACEMENT SHADOW_PENDING SWEEP EXPIRED RESOLUTION RANGE
9 M15 states Parent C1/C2/C3 edges are present in the YAML for sync/documentation, but the resolver runtime track is M15.

State Predicate Table

A row's when block is AND across features and OR within the listed states. Empty when means memory-only or lifecycle-only; it cannot be read from a single feature vector.

Lifecycle & Special Gates

The resolver is not a plain YAML lookup. The code adds state memory, lifecycle resets, funnel gates, sticky dwell, and optional engine-event injection.

Mechanism Source Effect
Feature supply check resolve() before state mutation Fails closed if a when-named feature is missing from the caller's supplied feature dict.
HTF reset thresholds.lifecycle Forces RANGE on HTF changes except protected states such as EXPANSION/RETEST, and can create pending displacement memory.
Gap / force reset resolve(force_reset=...) and gap lifecycle Terminates the active narrative to RANGE; forced engine-event replay can rebuild the active range unless it is a session-gap reset.
HTF-range sweep thresholds.sweep_geometry=htf_range Uses high/low/close versus frozen HTF range geometry for RANGE->SWEEP founding.
Displacement funnel _displacement_entry_allowed() Only from SWEEP; checks sweep age, direction, ATR body move, body ratio, and candle range.
Expansion funnel _expansion_entry_allowed() Allows EXPANSION from DISPLACEMENT with ATR-distance extension or from SWEEP/SHADOW_PENDING with pending displacement memory.
Retest funnel _retest_entry_allowed() Calls config_layer.retest_geometry.evaluate_retest_geometry(); fail-closed on missing range, direction, close, or ATR.
Sticky dwell _resolve_from_features() Keeps sticky states alive when no predicate matches, until age/lifecycle exit owns termination.
Engine injection engine_state_to Research-shadow path can honor engine transitions for SHADOW_PENDING and EXPANSION entry/exit.
