Parent track role

ParentCRTTrack classifies a stream of already-closed calendar parent candles into the disjoint 3-state sub-graph RANGE_C1 / MANIPULATION_C2 / DISTRIBUTION_C3. The M15 execution machine stays CRTEngine. The parent track reaches that machine only as process_candle(parent_state=bias, parent_objective=status).

Surface What it owns What it does not own
ParentCRTTrack One legal C1/C2/C3 edge per closed parent. ParentRange (C1 high/low) and ParentSweepEvent. bias is the sweep direction only while the state is DISTRIBUTION_C3. The M15 9-state machine. A clock. HTF posture. The objective enum. Any import of crt_engine_v2 at runtime.
ParentCandleBuilder Calendar-true closed parents for H1, H4, D1, W1, MN1. A close is reported on the first child of the next period. The in-progress accumulator stays private. The C1/C2/C3 classifier. HTFBuilder, which is the separate count-window clock that supplies htf_candle_id.
ParentCRTFeed One instance per instrument and parent rule. On each child bar: builder, then track, then classify_htf_state and resolve_objective. Exposes bias, state, htf_state, objective, last_range_ratio. A second copy of the walk. When parent_crt.enabled is false, from_prod_config() returns None and the engine keeps parent_state=None.
CRTEngine M15 execution. After an approved retest, the parent-bias elif can reject a direction that disagrees with a non-NONE parent_state. A later elif can apply the objective gate when that gate is enabled. The parent state names. HTFState is a second dimension and is never a CRTState.
Disjoint graph no edge joins the 9 M15 states and the 3 parent states Legal edges live in _crt_state_generated.VALID_TRANSITIONS, re-exported by state_identity.py.

C1 / C2 / C3 walk

on_parent_close(parent) takes exactly one closed parent and moves exactly one legal edge. The arriving candle becomes the new C1 on the first candle, on a C1 roll, on a failed C2, and on every candle after C3. A successful sweep keeps the existing C1 range. A confirmed impulse keeps that range and the sweep.

start: state RANGE_C1, range is None, bias NONE first closed parent -> RANGE_C1 bias NONE h_ref / l_ref = this candle RANGE_C1 boundary sweep, close back inside -> MANIPULATION_C2 bias NONE otherwise -> RANGE_C1 (roll) bias NONE MANIPULATION_C2 F-074 impulse away from swept side -> DISTRIBUTION_C3 bias = sweep direction otherwise -> RANGE_C1 bias NONE sweep cleared DISTRIBUTION_C3 next closed parent -> RANGE_C1 bias NONE this is the only legal edge
Current Allowed next Track behaviour
RANGE_C1 MANIPULATION_C2, RANGE_C1 Sweep stores a ParentSweepEvent and leaves the C1 range in place. No sweep calls _become_c1 and clears any sweep.
MANIPULATION_C2 DISTRIBUTION_C3, RANGE_C1 Impulse confirmation changes only the state. Failure restarts C1 on this candle.
DISTRIBUTION_C3 RANGE_C1 The next close always restarts. bias is live only during the child bars between the confirming close and that next close.
C1 reference parent high/low C2 sweep recorded, bias still NONE C3 the only state with a non-NONE bias

Sweep and impulse

The parent range object stays in parent_crt.py. The comparisons are the shared predicates structure.predicates.swept_high, swept_low, and directional_impulse (SP-001 / SP-002). A bar that only touches the level, or that closes exactly on it, is not a sweep.

Test Rule Result on the track
swept_high high > h_ref and close < h_ref Direction.SHORT. Sweep price is the candle high.
swept_low low < l_ref and close > l_ref Direction.LONG. Sweep price is the candle low.
both sides swept_high is tested first The event is SHORT. LONG is used only when the high was not swept.
impulse LONG close > open and close > sweep price Inherited from a low sweep. The impulse bar does not re-decide the side.
impulse SHORT close < open and close < sweep price Inherited from a high sweep. An unsigned large bar does not confirm.

ParentCRTFeed

The feed is the streaming adapter beside the backtest loop. config_layer does not import features. push(child) returns true only when a parent just closed and the track advanced on that closed candle.

each child candle ParentCandleBuilder.push(child) same period -> False, track unchanged new period -> close the previous buffer as one parent classify_htf_state(previous parent, this parent) first close stays HTFState.UNKNOWN ParentCRTTrack.on_parent_close(closed parent) resolve_objective(bias, C1 range, closed close) remember this parent as previous
Readout Meaning after push
bias ParentCRTTrack.bias. LONG or SHORT only in DISTRIBUTION_C3. Otherwise NONE, including the whole of MANIPULATION_C2.
state Current parent CRTState: RANGE_C1, MANIPULATION_C2, or DISTRIBUTION_C3.
htf_state Second dimension from classify_htf_state: UNKNOWN, REVERSAL, EXPANSION, DISTRIBUTION, ACCUMULATION. This DISTRIBUTION is a range-ratio posture. It is a different object from DISTRIBUTION_C3.
objective resolve_objective. NONE until a C3 bias exists. Then EXISTS, ACHIEVED, or INVALIDATED against the C1 bounds and the closed parent's close. Recomputed on parent closes, then held across the following child bars.
last_range_ratio Observation only: (curr.high - curr.low) / (prev.high - prev.low) of the last two closed parents. None before two closes. 1.0 when the previous range is not positive. The decision path does not read it.

HTF posture on two closed parents

Condition, in code order HTFState
Previous candle is bullish and this close is below its low, or previous is not bullish and this close is above its high REVERSAL
Close is outside the previous high or low. Both the ratio branch and the following branch return the same enum. EXPANSION
Close stays inside and range ratio >= distribution_min_range_ratio DISTRIBUTION
Close stays inside, including the band between the accumulation and distribution ratios ACCUMULATION

Objective versus the C1 range

Bias Target Invalidate Status from the closed parent's close
LONG C1 high C1 low ACHIEVED at or above the high. INVALIDATED below the low. Otherwise EXISTS.
SHORT C1 low C1 high ACHIEVED at or below the low. INVALIDATED above the high. Otherwise EXISTS.
NONE NONE. Also NONE when the C1 range or the close is absent.

Caller wire

On each backtest bar the feed is pushed before warmup handling and before process_candle. Warmup and the initialisation bar still advance the parent track. They return before the engine call. After initialisation, the engine receives the bias and the objective status that the feed is holding for the current child bar.

BacktestRunner bar HTFBuilder.push(candle) count-window id parent_feed.push(candle) if the feed exists _parent_closed is kept for the bar-structure snapshot the trade path does not branch on that flag warmup or initialise -> continue else process_candle( candle, htf.current_htf_id, parent_state = feed.bias or None, parent_objective = feed.objective.status or None)
Actor Contract
BacktestRunner ParentCRTFeed.from_prod_config(self.calendar) runs once, before HTFBuilder. htf_clock_basis="calendar" requires the feed. The calendar argument is the run's market calendar. None buckets timestamps as given.
identity.certify The L3 engine walk pushes the same feed and passes the same two keywords into process_candle.
research mirrors src/research/zone_mapping/* and crt_state_machine.py call process_candle without parent_state. The default stays None.
bias veto Reached on the approved-retest path, after the discount/premium zone filters. Requires parent_crt.enabled, a caller bias other than None and NONE, and an M15 state.direction different from that bias. Records FILTER_REJECTED with reason Against parent-timeframe bias (...), replays the retest as PARENT_BIAS, resets to RANGE. Action is TRADE_UNCONFIRMED when a resting order is flattened, otherwise FILTER_REJECTED.
objective veto The next elif. Requires objective_gate.enabled. allow_exists_only admits only ObjectiveStatus.EXISTS. The active file below has this gate off, so the branch is closed on that config.

F-089 records one XAUUSD gate-on versus gate-off comparison: the CRT event sequence and the trade set stayed the same, 4 of 19 rejection reasons changed from off_session to the parent-bias reason, and 0 outcomes changed. That is a recorded measurement on that corpus. It is not a new run of this page.

Config that arms the gate

configs/production/ACTIVE_VERSION read on 2026-10-12 contains v2_htfcrt_2026_08. from_prod_config is fail-fast: a missing parent_crt key raises. bias_gate_mode must be reject_on_mismatch. objective_gate.mode must be allow_exists_only. Any other mode raises, including when the section is disabled, because those keys are read before the enabled check.
