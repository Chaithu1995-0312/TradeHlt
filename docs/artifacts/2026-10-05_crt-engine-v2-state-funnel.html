CRT Engine v2 State Funnel

CRT Engine v2 — State Funnel Logic

Golden path: RANGE → SWEEP → DISPLACEMENT → EXPANSION → RETEST → EXECUTION → RESOLUTION

Core States (9-Member Execution Timeframe)

RANGE

Initial state. Waiting for a sweep on the active range boundary (h_ref / l_ref).

Entry: On reset via HTF boundary or timeout.
→ SWEEP
RangeDetector.detect_sweep() fires: candle crosses the range boundary.
→ SHADOW_PENDING
Pending displacement memory active + sweep confirms its direction.
Guard: Sweep age TTL countdown (SHADOW_PENDING only)
SWEEP

Liquidity sweep confirmed at range boundary. Waiting for impulse confirmation.

Entry: Range breakthrough detected.
→ DISPLACEMENT
try_sweep_to_displacement(): bar is directional and closes beyond the sweep price; |close−open| ≥ 1.2×ATR; body_ratio = |close−open|/(high−low) ≥ 0.65; (high−low) ≥ 1.0×ATR; sweep age ≤ 20 bars.
→ RANGE
Sweep expires (age > max_sweep_age_candles).
Guard: Directional impulse required (F-074); unsigned energy not legal
Guard: Max sweep age constraint (PATCH 2)
DISPLACEMENT

Directional impulse away from sweep confirms. Waiting for extension beyond impulse.

Entry: Close after sweep with proper impulse.
→ EXPANSION
try_displacement_to_expansion(): directional bar, close beyond displacement close, and |close − disp_close| ≥ 0.3 × ATR (expansion_atr_min_distance).
Guard: Strengthened expansion gate (PATCH 3): requires directional bar AND ATR distance
EXPANSION

Price extended beyond impulse. Waiting for retracement (retest) or TTL expiry.

Entry: Sustained move beyond displacement.
→ RETEST
try_expansion_to_retest(): depth = close − l_ref (LONG) or h_ref − close (SHORT); 0.1×ATR ≤ depth ≤ max(0.15×(h_ref−l_ref), 0.3×ATR); and displacement range/ATR (FM-028) ≤ 2.0. Soft confirmation is evaluated on the bars AFTER this.
→ EXPIRED
TTL exceeded: age > max_expansion_age_candles OR hours > max_expansion_age_hours.
→ RANGE
Stop breach: close at/through the stop a trade would use (entry_semantics guard).
Guard: Adaptive retest ceiling (PATCH 5) = max(range-based, ATR-based), plus a 0.1×ATR minimum-depth floor
Guard: TTL uses >, not ≥ (resolver parity)
Guard: Stop breach check (F-110); retest has priority over TTL on same bar
RETEST

Retest geometry passed on the previous bar; soft confirmation now evaluates each following bar (up to 3).

Entry: retest geometry passed (see EXPANSION). Entry price = RETEST close.
→ EXECUTION
S = G^0.7 × C^0.3 ≥ 0.3 (tier 1 at ≥ 0.75), where C = max(0.2, 0.7·Σ w·f + 0.3·min(f_body, f_mom)); then discount/premium zone vs range midpoint, parent bias, objective and session filters.
→ RANGE
Soft-conf timeout: no qualifying manifold within soft_conf_max_candles OR filter rejection.
Guard: Soft-confirmation manifold: EMA2/EMA5 momentum, Gaussian depth decay, body ratio, displacement strength
Guard: Parent-timeframe bias (C3 distribution veto)
Guard: Session window filter
Guard: Range position (discount/premium zone required)
EXECUTION

Trade approved and opened. Managing fills: SL, TP1 partial, TP2 runner.

Entry: Trade object created; SL/TP levels locked from entry bar.
→ RESOLUTION
Any exit fires: STOPPED (SL), TP1 (partial 50%), TP2 (runner), timeout.
Guard: Multi-TP walk (SEM-017): SL-first tie-break, not declared order
Guard: Displacement-origin kill (SEM-021): close at/through origin before TP2 forces exit
Guard: Trade TTL: closure if age ≥ trade_ttl_candles on quiet bar
RESOLUTION

Trade closed. Record outcome and prepare for next cycle.

Entry: Any exit event (SL, TP1, TP2, timeout, structural kill).
→ RANGE
Post-resolution reset: clears all geometry, resets phase counters, seeds new range.
Guard: None (terminal state); reset is deterministic

Archive & Defer States

EXPIRED

One-candle soft-archive state. EXPANSION TTL exhausted before RETEST fired.

Entry: EXPANSION → EXPIRED when age > TTL.
→ RANGE
Automatic reset on the same candle (or next bar).
Guard: Phase 3b soft archive; records episode label (candidate_id) before reset
SHADOW_PENDING

HTF displacement memory active; awaiting matching M15 sweep to resume.

Entry: HTF reset creates pending_displacement; M15 enters RANGE with pending.
→ SWEEP
(Internal: M15 sweep detected; memory consumed)
→ EXPANSION
try_shadow_pending_to_expansion(): resume cross-window setup (collapse SWEEP).
→ RANGE
SHADOW_LEAK: stored sweep direction ≠ pending direction OR integrity failure.
Guard: TTL countdown on creation (separate from EXPANSION TTL)
Guard: Direction match required on resume

Critical Logic Flows

Entry-Bar Lookahead Guard (F-110)
RETEST bar: entry price = RETEST close in both entry semantics.
Legacy approval-bar semantics: the trade object (SL/TP from that bar's ATR) is built on the approval bar, one or more bars later, and that bar is not walked for SL/TP (F-110). resting_order semantics instead fills at the RETEST close and walks the soft-confirmation bars. Which one is active was not verified.
TTL Boundary Condition (>= vs >)
Engine rule: age > max_age (strict exceeded, not at-or-exceeded).
Resolver parity: changed from >= to > to match engine (F-068).
Example: age==495 stays EXPANSION; age==496 expires (max=495).
Displacement-Origin Kill (SEM-021)
Precedence: absolute — structural kill runs before update_trade (TP2/SL).
Precedence: after_resting_fills — SL/TP resolve first; kill only fires on TP1 bar (result="UNCHANGED"/"TP1").
Rule: If close at/through origin (displacement candle close breached), force-exit the runner before TP2 can fire.
Soft-Confirmation Manifold (RETEST → EXECUTION)
Trigger: RETEST locked; evaluating_soft_conf=True.
Gate: f_body = min(1, body_ratio/0.6); f_mom = clip((EMA2−EMA5)·dir/ATR, 0, 1); f_dist = exp(−(depth/ceiling)²); f_disp = min(1, |disp move|/(1.5·ATR)).
Window: soft_conf_max_candles = 3 (active config) before timeout reset.
Outcome: Approved → EXECUTION; rejected → RANGE.

Formulas (source-verified)

Building blocks
True range: TR = max(H−L, |H−Cprev|, |L−Cprev|)
ATR: simple mean of the last 14 TRs (not Wilder), absolute price units; differs from the close-relative canonical atr (FM-041).
body_ratio (FM-010): |close−open| / (high−low); 0 if high−low ≤ 0.
Range: h_ref = max high, l_ref = min low of last 14 candles at reset; equilibrium = (h_ref+l_ref)/2.
Sweep: SHORT if high > h_ref and close < h_ref; LONG if low < l_ref and close > l_ref (strict).
FM-027 displacement_retrace: clip(|retest_close − disp_open| / |disp_close − disp_open|, 0, 1).
FM-028 displacement_atr_ratio: (disp high−low) / ATR.
Fusion: S = G0.7 × C0.3, G = 0.35·sweep + 0.25·breakout + 0.20·retest + 0.20·time.
Stop / targets: SL = disp_low − 0.2·ATR (LONG) or disp_high + 0.2·ATR (SHORT) for the default anchor; TP1 = entry ± m·risk (m 0.8–1.5 by intent); TP2 = entry ± 2·risk.

Values are from active config v2_htfcrt_2026_08; per-instrument overrides not checked. Funnel rate statistics were removed: the earlier figures came from resolver state occupancy, not engine transitions.

  • PATCH 4: Event timestamping on every transition; auto-assign candle.index
  • PATCH 5: Adaptive retest depth (ceiling = max of range% or ATR%)
  • PATCH 6: Time-decay scoring (exp decay since retest, shadow age penalty)
