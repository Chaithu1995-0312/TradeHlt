Lab rules

  • Run a layer, never re-implement it. Exceptions: R5 twins, F-077 independent objects.
  • Research imports execution; execution never imports research.
  • Run unit: ExperimentSpec = N Setups × corpus, authority NONE.
  • Compare on equity at a fixed risk_pct. R is never ranked across stop anchors (can_compare denies it).
