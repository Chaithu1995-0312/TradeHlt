### 2. `compress_logs_for_llm.py`

**File Purpose:** Streaming log compressor that reads one or more JSONL opportunity/fusion logs and produces a token-efficient statistical summary for LLM consumption (governance orchestrator, hypertuning prompts). Never loads full logs into memory.

**Runtime Role:** Called by governance orchestrator as a pre-processing step before LLM inference. Also usable as standalone CLI. The output schema (`{summary, data, anomalies}`) matches `reflection_buffer_advanced.py --compressed-summary`.

**Trust Classification:** LIVE — actively wired into governance pipeline per docstring reference.

**Classes:** None.

**Methods/Functions:**

- `_iter_records(paths: Iterable[Path])` — generator that walks a list of file paths, yielding JSON-decoded dicts line-by-line.
  - **Purpose:** Stream from multiple log files, skipping unreadable or malformed lines.
  - **Invocation:** Called once by `compress()`.
  - **Fallbacks:** `OSError` → `logger.warning` + `continue` to next file. `json.JSONDecodeError` → `continue` to next line. **Silently skips bad lines — no count logged.**
  - **Side effects:** Opens file handles.
  - **Failure modes:** If all paths fail `OSError`, generator yields zero records → outer `compress()` raises `ValueError("No records found")`.

- `_quantile(sorted_xs: list[float], q: float) -> float` — approximate quantile via index rounding.
  - **Purpose:** Compute p10/p50/p90 for RR distribution.
  - **Risk:** Round-to-nearest index can bias quantiles, especially on small samples. Returns `0.0` for empty lists — silent default.

- `compress(paths: list[Path], top_n_features: int = 8) -> dict`
  - **Purpose:** The core aggregator. Streams all records, computes aggregate stats, per-feature correlations with RR, TP_HIT vs SL_HIT feature deltas, and anomaly detection.
  - **Inputs:** List of JSONL paths, top N features for correlation/delta output.
  - **Outputs:** Dict with keys `summary`, `data`, `anomalies`.
  - **What actually happens at runtime:**
    1. Iterates every record across all files.
    2. Extracts `outcome`, `direction`, `instrument`, `rr_achieved`, `mae`, `duration_candles` with `str()`/`float()`/`int()` coercion (defaults: "UNKNOWN"/0.0/0).
    3. If `features` is a dict, accumulates streaming sums for Pearson correlation: sum_x, sum_x2, sum_xy per feature.
    4. Separately accumulates feature sums for TP_HIT and SL_HIT buckets to compute deltas.
    5. Captures first 32 severe MAE (≤ -0.005) outliers.
    6. After streaming: computes RR mean/std/quantiles, Pearson correlations (minimum 30 samples per feature), TP-minus-SL deltas, anomaly clusters (>70% outcome share).
    7. Returns summary dict.
  - **State mutations:** None globally. Returns new dict.
  - **Side effects:** Reads files only.
  - **Hidden defaults:** `top_n_features=8`, `mae <= -0.005` threshold for severe MAE, `count < 30` correlation filter, `share > 0.7` anomaly threshold.
  - **Failure modes:** ValueError if no records. Division by zero guarded (denom ≤ 1e-12 check). Correlation denom at line 149: `math.sqrt(var_x * rr_var)` — if `rr_var` is 0 (all RR identical), correlation loop silently skips. No warning logged.

- `_read_run_id_from_jsonl(path: Path) -> str`
  - **Purpose:** Reads first line of a JSONL, checks if it's a run_header record, extracts run_id.
  - **Runtime:** Only called when --instrument is given and --output is not, to construct run-scoped output path.
  - **Fallback:** Returns empty string on any exception.

- `_expand_globs(patterns: list[str]) -> list[Path]`
  - **Purpose:** Resolves glob patterns to sorted file paths. If a pattern matches nothing, treats it as a literal path.
  - **Runtime:** Called at start of main().
  - **Failure mode:** If a non-matching glob is actually a missing file, caught later by existence check.

- `main(argv=None) -> int`
  - **What actually happens at runtime:**
    1. Parses `--logs` (required), `--output`, `--instrument`, `--run-id`, `--top-n-features`.
    2. Expands globs, checks all files exist (prints errors to stderr, return 1).
    3. Resolves output path: if `--output` not given but `--instrument` is, constructs `logs/{instrument}/{run_id}/compressed.json` (reads run_id from first file header if not provided explicitly).
    4. If neither `--output` nor `--instrument` provided: prints ERROR, return 1.
    5. Calls `compress()`, writes result to output file (creates parent dirs).
    6. Logs count and prints `OUTPUT:compressed:{path}`.
  - **Side effects:** Writes JSON file to disk. Creates directories.
  - **File writes:** `args.output` (JSON).
  - **Failure modes:** Missing files → error exit. No records → ValueError propagates up.

**Fail-Fast / Fallback Audit:**
- **Swallowed exceptions (continue silently):** Bad JSON lines, unreadable files, non-dict features, non-float feature values.
- **Silent correlation skip:** If `rr_var == 0`, all correlations silently omitted from output.
- **No warning on empty anomaly sections:** `severe_mae` capped at 32 entries silently. `sl_clusters` may be empty with no indication.
- **Numeric coercion hardening:** All `rec.get()` values wrapped with `float()`/`int()` with `or 0.0` fallback — could mask missing data.
- **Determinism:** Deterministic given same input files and feature ordering.

### 2. `manual_backtest.py`

**File Purpose:** Standalone, self-contained CRT backtest engine implementing the complete CRT pipeline from scratch: ATR, sweep detection, displacement, expansion, retest, Gaussian scoring, soft confirmation, fusion scoring, regime detection, dynamic thresholds, tiered position sizing, trade management. This is the reference implementation of the CRT strategy logic, independent of the `src/runtime/` codebase.

**Runtime Role:** Manual backtesting tool. Used for quick strategy evaluation on a single CSV. Also serves as the canonical CRT logic reference (the constants at the top are described as "real EURCAD calibrated parameters"). Runs validator connector at end as optional hook.

**Trust Classification:** LIVE (as reference implementation). The docstring says "Runs the full CRT pipeline on any M15 CSV exactly per the spec."

**Classes:**

- `DynamicThreshold`
  - **Purpose:** Adaptive score threshold based on recent win/loss history. Tightens threshold when losing streak, loosens when winning streak.
  - **Ownership:** Per-backtest-run state.
  - **Runtime responsibility:** Called before each trade entry decision. Updates after each trade closes.
  - **Methods:**
    - `update(win: bool)` — appends win/loss to rolling window (max 20), pops oldest if over limit.
    - `threshold() -> float` — returns `DYN_TIGHT(0.70)` if win rate < 0.45, `DYN_LOOSE(0.58)` if > 0.60, else `DYN_MID(0.65)`.
    - **Hidden defaults:** `DYN_WARMUP=10` trades before threshold kicks in (returns 0.65 during warmup). `DYN_WINDOW=20`.

**Key Functions:**

- `find_csv() -> str`
  - **Runtime:** Searches `/mnt/user-data/uploads/` for CSVs. Hardcoded paths for XAUUSD and BTCUSDT. Falls back to first `.csv` in directory.
  - **Failure:** `FileNotFoundError` if no CSV found.
  - **Trust:** This is a container/Colab-specific path. Will not work on standard desktop.

- `adverse_slip(atr: float) -> float`
  - Uses dedicated `rng_slip = random.Random(42)` — deterministic per-seed.

- `gaussian(x, mu, s2) -> float`
  - Pure Gaussian PDF (unnormalized). `exp(-(x-mu)^2 / s2)`.

- `atr(candles: list) -> float`
  - Standard ATR with period=14. Computes TR from (o,h,l,c) tuples. Falls back to candle range if <2 candles available.

- `body_ratio(o, h, l, c) -> float`
  - Returns `abs(c-o) / (h-l)`. Returns 0.0 if range is 0.

- `wick_size(o, h, l, c) -> float`
  - Returns `h - l`. Named confusingly — returns total range, not wick. But used as "strength" metric.

- `gaussian_score(retest_depth, body_rat, disp_str, candles_since) -> dict`
  - **What actually happens at runtime:**
    1. Hard range-checks: reject if retest_depth outside [0.025, 0.469] or disp_str > 3.670.
    2. Computes 4 sub-scores: retest Gaussian, body Gaussian, displacement Gaussian, time decay (exp(-0.05 * age)).
    3. Weighted product: score = s_r^0.40 * s_b^0.35 * s_d^0.25 * s_t^0.15.
    4. Logistic sigmoid: p_win = 1/(1+exp(-4.5*(score-0.50))).
    5. Returns `{score, p_win, reject}`.
  - **Hardcoded constants:** `G_RETEST_MU=0.237, G_RETEST_S2=0.040, G_BODY_MU=0.847, G_BODY_S2=0.021, G_DISP_MU=2.177, G_DISP_S2=1.196, G_DECAY_LAM=0.05, G_SIG_K=4.5, G_SIG_X0=0.50, G_RETEST_MIN=0.025, G_RETEST_MAX=0.469, G_DISP_MAX=3.670`.
  - **Failure mode:** If retest_depth is out-of-bounds, returns score=0, reject reason string. Caller must check `gs["reject"]`.

- `soft_conf_score(candle_ohlcv, direction, ema_fast, ema_slow, atr_val, h_ref, l_ref, range_size, disp_body) -> float`
  - **What actually happens at runtime:**
    1. Computes 4 sub-scores: body ratio (capped at body_min=0.60), EMA momentum (normalized by ATR), non-linear distance from retest boundary (Gaussian falloff via `exp(-(depth/ceiling)^2)`), displacement inheritance.
    2. Linear combination with weights (0.35, 0.35, 0.15, 0.15).
    3. Weakest-link penalty: `C = 0.7*C_lin + 0.3*min(f_body, f_mom)`.
    4. Returns `max(0.20, C)`.
  - **Hidden defaults:** `CONF_BODY_MIN=0.60`, `CONF_FLOOR=0.20`, `WEAK_LINK_WT=0.30`.

- `fusion_score(G, C) -> float`
  - Returns `G^0.70 * C^0.30`. Weighted product of Gaussian and soft confirmation scores.

- `detect_regime(atr_val, price, prev_close, close) -> str`
  - Returns "EXPANSION" if vol > 0.15% and trend > 1.2×ATR, "DEAD" if vol < 0.04%, else "NEUTRAL".
  - **Hidden defaults:** `VOL_HIGH=0.0015`, `VOL_LOW=0.0004`, `TREND_STR_HIGH=1.2`. These are raw ratios, not percentages.

- `risk_multiplier_for(regime) -> float`
  - EXPANSION→1.2x, DEAD→0.5x, NEUTRAL→1.0x.

- `load_csv(path) -> list`
  - **What actually happens at runtime:**
    1. Tries multiple date formats: `%Y-%m-%d %H:%M:%S`, `%Y-%m-%d %H:%M`, `%Y.%m.%d %H:%M:%S`, `%Y.%m.%d %H:%M`.
    2. Auto-detects column indices by header name (case-insensitive, lowercased).
    3. Handles `utf-8-sig` BOM. Handles `adj close` alt name for close column.
    4. Skips unparseable rows silently.
    5. Sorts by timestamp ascending.
  - **Failure modes:** If no column matches close/open/high/low, indices fall through to positional defaults (1,2,3,4) — may pick wrong columns silently. If `ti` not found, defaults to index 0.
  - **Side effects:** None.

- `run(csv_path) -> list[dict]`
  - **What actually happens at runtime:** This is the full backtest loop. 600+ lines of sequential state machine.
  
  **High-level runtime flow:**
  1. Loads CSV → list of candles.
  2. Extracts instrument name from filename.
  3. Initializes capital, tracking stats, engine state variables.
  4. Rolling candle buffer for ATR (max 3×ATR_PERIOD=42). HTF buffer grows unbounded.
  5. EMAs updated every candle.
  6. Warmup = ATR_PERIOD*3 + HTF_CANDLES = 42+16 = 58 candles.
  7. **State machine loop** (per candle):
     - **RANGE:** Detects sweep when price breaks HTF range high/low and closes back inside.
     - **SWEEP:** Up to 30 candles. Looks for displacement candle (1.2×ATR move, 0.70 body, 1.5×ATR wick).
     - **DISPLACEMENT:** Checks expansion guard (price continues 0.2×ATR beyond displacement close).
     - **EXPANSION:** Checks retest depth ≤ min(0.25×range, 0.5×ATR) from boundary. On retest, transitions to soft confirmation.
     - **SOFT_CONF:** Up to 3 candles. Computes Gaussian score + soft confirmation + fusion score. Compares against dynamic threshold. If S >= TIER2(0.55) AND threshold, and position is inside range mid-line, enters trade.
     - **Trade management:** Monitors SL, TP1 (trail conceptually), TP2. SL exits at exact SL price (gap-through protection). Spread and slippage applied on both entry and exit.
  8. Gap reset (>120 min gap) when no active trade — resets all state.
  9. Force-close at end of data.
  
  **Key runtime details:**
  - Entry fill includes spread and slippage. Exit fill also includes spread and slippage.
  - Position sizing: tiered (full risk if S ≥ 0.75, half risk otherwise) × regime multiplier.
  - SL anchored to displacement candle extreme ± 0.2×ATR buffer.
  - TP1 = 1×ATR, TP2 = 2×ATR from entry.
  - Inverted SL guard prevents SL on wrong side of entry.
  - Range position filter: entry must be on opposite side of range mid-line from the direction.
  
  **State mutations:**
  - Mutates closure variables: `capital, peak_capital, cum_r, peak_cum_r, max_dd_r`.
  - Appends trade dicts to `trades` list.
  - Resets engine state variables via `reset()` function.
  
  **Failure modes:**
  - If CSV has 0 candles: `candles[0][0]` IndexError.
  - `range_size==0` causes `ceiling == 0`, leading to division by zero guard at `ceiling > 0` check in soft_conf_score.
  - ATR with insufficient data: falls back to candle range.
  - Infinite loop not possible — fixed candle iteration.

- `analyse(trades) -> dict`
  - Computes win rate, avg RR, profit factor, Sharpe, max drawdown (R-curve), Gaussian-RR correlation.
  - **Hidden defaults:** Correlation requires ≥3 scored trades, else returns NaN.

- `log_run(stats, instrument)`
  - Appends run stats to `results/tracking/runs.csv`. Creates file with header if not exists.
  - **Side effects:** File append. Creates directories.

- **CLI entry point:**
  - Parses `--csv` optional argument. Falls back to `find_csv()`.
  - Writes trades CSV to `results/manual/{instrument}_{timestamp}.csv`.
  - Runs `analyse()`, prints summary to stdout.
  - **Validator connector hook:** Attempts to run `trade_replay_validator.validate_all()` against a hardcoded `results/manual/manual_trades.csv` path — this will likely fail since trades are written to a timestamped path, not `manual_trades.csv`. This is a bug.
  - **Failure modes for validator hook:** Exception caught and printed, does not crash main execution.

**Fail-Fast / Fallback Audit (critical):**
- **Column auto-detection with silent positional fallback:** If CSV header has non-standard names, column indices default to 1,2,3,4 (open, high, low, close) which would produce garbage data with no warning.
- **Unbounded HTF buffer:** `htf_buf` grows without bound (only trimmed when > HTF_CANDLES+1 for range computation, but entries are never removed from the list). Memory leak over long backtests.
- **Gap reset only when NOT in trade:** If a trade is open during a gap/weekend, the engine state is NOT reset. The trade continues, but after the gap, the range/retest references may be stale. However, this only happens mid-trade, so the trade has already set its SL/TP — no corruption.
- **Validator connector uses wrong file path:** Hardcoded `results/manual/manual_trades.csv` instead of the timestamped output file. This is a bug that silently fails inside try/except.
- **No minimum trade length check:** Trade can trigger and close in same candle if TP is immediately hit.
- **Hidden state leakage:** `concat` as local closure variable is used but not reset — when multiple trades are within a single HTF window, stale references persist.
- **Numeric stability:** `risk_dist == 0` check at entry — correct guard against division by zero.
- **Unbounded HTF buffer** (`htf_buf`): Not a leak if backtest completes, but could slow down extremely long runs.
- **`cached_feat` stale reference:** If `cached_feat` is set during EXPANSION but `eval_soft_conf` evaluates to false and resets, `cached_feat` is not cleared until next `reset()` call or next retest. Low risk but not clean.

**Determinism:** Pseudo-deterministic given seed=42 for slippage RNG. Gaussian scoring is deterministic. File iteration order is deterministic (sorted CSV). All random state is isolated in `rng_slip`.

### 8. `prepare_data.py`

**File Purpose:** Comprehensive data preparation pipeline that loads raw M1 OHLCV data from multiple formats (histdata.com, Binance klines, standard CSV), resamples to M15, validates integrity, and writes clean M15 CSVs. Also includes a validation-only mode to scan and report on existing data files.

**Runtime Role:** Core data preprocessing. Used both standalone and imported by `unified_data_builder.py`. All sub-parsers are imported by the unified builder.

**Trust Classification:** CANONICAL — core data pipeline. Both standalone and importable.

**Classes:** None.

**Methods/Functions:**

- `parse_histdata(filepath) -> list[tuple]`
  - **What actually happens at runtime:**
    1. Opens file (utf-8-sig BOM handling).
    2. Skips lines starting with "Date" or "date".
    3. Auto-detects comma or semicolon delimiter.
    4. Parses `%Y%m%d %H%M%S` timestamp format.
    5. Handles missing volume (defaults to 0.0).
    6. Skips unparseable lines silently.
  - **Failure modes:** If first field has unexpected format, `strptime` raises ValueError → line skipped. No line counter on skips.

- `parse_binance(filepath) -> list[tuple]`
  - **What actually happens at runtime:**
    1. Reads CSV with `csv.reader`.
    2. Detects header row (checking if first field is all-digits).
    3. If first row is actually data (not header), processes it.
    4. Parses `open_time` as Unix milliseconds → Python datetime via `utcfromtimestamp(ms/1000)`.
    5. Handles missing volume (defaults 0.0).
    6. Skips malformed lines.
  - **Risk:** `datetime.utcfromtimestamp()` is deprecated in Python 3.12+ (uses `aware` utc but returns naive datetime). Timestamps are technically UTC but has no tzinfo.

- `parse_standard(filepath) -> list[tuple]`
  - **What actually happens at runtime:**
    1. Reads first line as headers. Lowercases all headers.
    2. Auto-detects column indices: timestamp/datetime/date/time, open/o, high/h, low/l, close/c/adj close, volume/vol.
    3. If any of ts, o, h, l, c not found, raises ValueError.
    4. Tries multiple date formats: `%Y-%m-%d %H:%M:%S`, `%Y-%m-%d %H:%M`, `%Y/%m/%d %H:%M:%S`, `%d/%m/%Y %H:%M:%S`, `%Y-%m-%dT%H:%M:%S`.
    5. Skips unparseable rows.
  - **Failure modes:** If column detection fails, raises ValueError (clear error with headers listed).

- `resample_m15(m1_rows) -> list[tuple]`
  - **What actually happens at runtime:**
    1. Buckets M1 rows by 15-minute boundary (floor minute/15 * 15).
    2. Sorts bars within each bucket by time.
    3. Computes OHLCV: open=first, high=max, low=min, close=last, volume=sum.
    4. **Integrity filter:** Drops any M15 candle where `high < max(open, close)` OR `low > min(open, close)` OR `high == low`. These indicate bad data or no-trade intervals (zero-range candles filtered).
    5. Includes partial buckets (1-14 M1 bars) — doesn't require all 15 bars.
  - **Hidden behavior:** Partial buckets at session open/close are included. This means the first/last M15 candles of a trading session may have fewer than 15 M1 sub-bars.

- `validate(rows, instrument) -> dict`
  - **What actually happens at runtime:**
    1. Checks time ordering (stops after 3 issues).
    2. Counts OHLC integrity violations (`h < max(o,c)` or `l > min(o,c)`).
    3. Counts zero-range candles (`h == l`).
    4. Detects intra-week gaps > 2 hours (skips Friday→Monday and weekend days).
    5. Computes calendar days and approximate trading days (×5/7).
  - **Hidden behavior:** Does NOT count duplicate timestamps (no key in stats dict). The `duplicates` key referenced in `validate_existing` is never set by this function.

- `write_csv(rows, filepath)`
  - Writes standard header and rounded values (OHLC to 5 decimal places, volume to 2).

- `process(source, files, instrument, output_dir, already_m15) -> str`
  - **What actually happens at runtime (the pipeline):**
    1. Selects parser by source.
    2. Loads each file, extends `all_rows`.
    3. Sorts chronologically, deduplicates by timestamp (set-based).
    4. Converts all timestamps to UTC-aware (via `replace(tzinfo=timezone.utc)`).
    5. If `--already-m15`, skips resampling. Otherwise resamples M1→M15.
    6. Validates output.
    7. Writes to `{output_dir}/{instrument}_M15_real.csv`.
    8. Returns output path.
  - **Hidden behavior:** UTC assignment is via `replace()` not `tz_localize()` — this blindly stamps UTC on timestamps without converting. If timestamps were in another timezone, they become incorrectly labeled as UTC.

- `validate_existing(data_dir)`
  - Scans for `*_M15.csv` files (not `*_real`), validates each, does gap distribution analysis.
  - Classifies gaps: 30/45/60/75 min = expected session breaks, <4320 min = unexpected, ≥4320 min = weekend/holiday.
  - Reports pass/fail per instrument and overall.
  - **Hidden behavior:** Looks for `*_M15.csv` (not `_M15_real.csv`). References `stats.get("duplicates", 0)` but `validate()` doesn't return a "duplicates" key → always 0.

- `main()`
  - CLI entry point. Supports `--validate-only` mode and full pipeline mode.

**Fail-Fast / Fallback Audit:**
- **`process()` UTC handling:** Line 335: `dt.replace(tzinfo=timezone.utc)` — this is a blind timezone label assignment, not a conversion. If the original timestamps were in a local timezone (e.g., histdata.com uses UTC but some sources use local), this creates incorrect UTC-labeled timestamps that are off by the zone offset. This is a corruption risk.
- **`validate()` missing "duplicates" key:** `validate_existing()` references `stats["duplicates"]` but `validate()` never sets it. This silently evaluates to 0 in the `all_ok` check on line 413 via `dict.get("duplicates", 0)`, so it's not a crash but is misleading.

### Governance Contamination Risks

- **`build_rr_dataset.py` version string collision:** Auto-generated `YYYYMM_v1` can collide within same month, silently overwriting previous versioned dataset.
- **`compress_logs_for_llm.py`:** If governance pipe consumes corrupted summary (correlations from <30 samples skipped silently), LLM decisions are based on incomplete data with no warning.
- **Auto-promotion in `build_rr_dataset.py`:** `_register_dataset` auto-promotes if no active RR version exists. If a bad dataset is built first (e.g., from incomplete opportunity scan), it becomes the active version before a good one is registered.

### Replay / Live Drift Risks

- **Schema drift between zone_registry_builder and FeaturePipeline:** Zone centers are raw feature vectors. If `CANONICAL_FEATURES` order changes (feature addition/removal), pre-computed zones become silently invalid. No schema version embedded in zone JSON.
- **`manual_backtest.py` calibrated constants:** The Gaussian parameters are labeled "real EURCAD 2024-2025, 200 retest observations." If market regimes shift, these static parameters become stale. No recalibration trigger.
