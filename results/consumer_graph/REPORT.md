## How edges and statuses are established
- **Edges** (89): {'absence': 1, 'ast': 78, 'ast+file': 7, 'config': 1, 'none': 1, 'static_text': 1}. `ast` edges come from import statements and symbol references in the repository with file:line evidence; `absence` is a repository-wide search that found nothing; `config` is the production config value; `static_text` is a parsed text mirror (C++ feature order). Edges are not data-flow proofs; parity evidence is separate.
- **Statuses** come from in-memory execution on 700 bars of XAUUSD M15 (July 2025) and on the repository artifacts. Allowed values: verified, mismatched, broken, unverified. "Verified" requires executed parity evidence and a complete dependency path.
- Not established: anything outside the repository (external callers), the C++ binary's behavior, TradeNet loading (no torch installed), runtime `sys.path` edits behind bare-name imports.
