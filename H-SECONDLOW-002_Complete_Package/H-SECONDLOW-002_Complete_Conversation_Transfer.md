## 1. Original Goal

Build a clean, standalone, read-only diagnostic tool to detect **20-day second-low purges** on XAUUSD M15 data and measure what happens in the exact next 2 hours (8 bars), with strict no-lookahead rules and proper event debouncing.

Key requirements from the start:
- Daily resampling + `.shift(1)` for levels (no lookahead)
- Stateful latch to avoid event spam
- Exactly 8 post-purge bars (positional indexing + hard validation)
- Dual-unit purge depth (price + ATR)
- Separate research harness (never touch production `purge_delay_scan.py`)

## 2. Major Turning Points & Decisions

### Phase 1: Initial Script & Design
- Created `scripts/analysis/purge_delay_scan.py`
- Decided on **second-lowest daily Low** instead of absolute lowest
- Implemented strict 8-bar post-window with validation

### Phase 2: First Results on 1-Month Data
- Ran on `XAUUSD_M15_1year.xlsx`
- Result: **16 raw events**, **7 independent events** (after 120min spacing)
- Initial aggregate stats looked positive

### Phase 3: Forensic Correction (Critical Shift)
Multiple detailed critiques correctly identified that:
- The positive aggregate result was driven by **only 2 tail events**
- The other 5 events were mostly chop/weak
- We needed **event-level forensic analysis**, not more aggregate statistics

This led to deep forensic work on the 7 events (normalized trajectories, path types, pre-event context, purge rejection, prior interaction history).

### Phase 4: Hypothesis Narrowing & Freezing
After forensic analysis, the hypothesis was narrowed to the conjunction of two pre-event conditions:

**H-SECONDLOW-002 v1.0 (FROZEN)**

- **EXPOSED** = `pre_2h_return_atr <= -2.0` **AND** `purge_depth_atr >= 1.5`
- Primary endpoint: `close_disp_atr` at exactly +120 minutes
- Primary effect estimand: median(EXPOSED) − median(BASELINE)
- Clear decision rules with precedence (INSUFFICIENT checked first)
- Discovery slice (2026-04-17 → 2026-05-22) **permanently excluded** from confirmatory evidence

### Phase 5: Governance & Provenance Issues
- Decision rule precedence was clarified
- Discovery exclusion must happen at the **event level** after full detection (not by deleting OHLCV rows before running the detector)
- Previous "full corpus" report was invalidated because it reused discovery events

### Phase 6: Full Corpus Audit Problem (Current Blocker)
When attempting to run on the full `XAUUSD_M15.csv`:
- The sandbox environment returned **0 events**
- Root cause: `second_low_20d` computation produced **0 non-NaN values** on the long gapped series (weekends/holidays break the rolling logic in this environment)
- Therefore, reliable PRE_DISCOVERY / DISCOVERY / POST_DISCOVERY counts could **not** be produced in the sandbox

## 4. Frozen Hypothesis Contract (H-SECONDLOW-002 v1.0)

**Status**: FROZEN — 2026-07-06

**Population**  
Independent XAUUSD second-low purge events generated by frozen SECONDLOW-v1 detector + 120min independence rule.

**Exposure Definition (Pre-Event Only)**
- Condition A: `pre_2h_return_atr <= -2.0`
- Condition B: `purge_depth_atr >= 1.5`
- **EXPOSED** = A AND B
- **PARTIAL** = exactly one of A or B
- **BASELINE** = neither

**Primary Endpoint**  
`close_disp_atr` at exactly +120 minutes.

**Primary Effect Estimand**  
`median(close_disp_atr | EXPOSED) − median(close_disp_atr | BASELINE)`

**Decision Rules (with Precedence)**
1. INSUFFICIENT if exposed_n < 30 OR baseline_n < 30
2. FAIL_DIRECTION if sample-size gate passes AND primary effect <= 0
3. PROMISING_NOT_CONFIRMED if sample-size gate passes but OOS/robustness requirements incomplete
4. SURVIVES_INITIAL_TEST only if all criteria pass (including chronological OOS)

**Discovery Data (Permanently Excluded)**  
2026-04-17 → 2026-05-22

**Artifact Versioning** (must be recorded with every run)
- contract_hash, detector_version, source_sha256, independence_rule_version, etc.
